# PulseChat — Real-Time Chat Application

A modern real-time chat application built for Prodigy InfoTech Task 04.

## Core requirements
- Account creation and authentication
- WebSocket-powered real-time messaging
- Public chat rooms
- Private conversations
- Text message exchange

## Enhanced features
- Persistent chat history
- Notifications and unread counts
- Online/offline presence
- Typing indicators
- Multimedia/file sharing
- Responsive 2026-style chat UI

## Architecture
Client UI + Node.js WebSocket server + persistent database, with environment-based configuration and production-safe defaults.

## Status
Build in progress.
